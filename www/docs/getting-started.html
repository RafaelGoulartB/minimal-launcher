Getting started

From installation to a calm new Home screen in a few minutes.

Install and choose your Home app

  1. Download the latest APK from the GitHub release and install it on an Android 8.0 (API 26) or newer device.
  2. Press the device Home button. Android will ask which Home app to use; select Minimal Launcher.
  3. If Android does not prompt you, open the device settings and look for Default apps or Home app, then select Minimal Launcher.
Changing your mind is safe. Your previous launcher remains installed. You can select it again at any time in Android's default Home app settings.

Your first Home screen

Open the app list with a left swipe. Long-press an app to add it to Home, rename it, hide it, or create a folder. Back on Home, long-press and drag an item to place it where you want it.

Optional Home information

Open Settings from the app list to choose whether Home shows the date, battery level, and today's usage total. You can also pick a clock format, text size, typeface, and accent color there.

Build from source

For local development, Android Studio with its bundled JDK (or JDK 17) and Android SDK 37 are required. From the repository root:

make doctor
make debug
make run DEVICE=emulator-5554
